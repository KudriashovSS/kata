# Прототип: база технических фактов о проекте

Инвертируем задачу системного анализа: не проектируем схему знаний заранее и не предсказываем
будущее — агент **реверс-инжинирит технические факты из уже существующего кода**, человек только
выбирает нужные срезы и ревьюит сомнительное. Дальше эта память живёт рядом с проектом,
актуализируется при каждой задаче и (гипотеза) делает будущие реализации качественнее и дешевле.

Наша работа = **хороший скилл + честные эвалы**. Всё остальное делает фронтир-модель на вайбе.

## Как это выглядит для пользователя

1. Ставит скилл `tech-facts` и говорит агенту: «построй базу технических фактов о проекте».
2. Агент разведывает репозиторий и поднимает **локальный UI на одном порте** (`localhost:4747`):
   лендинг-picker со срезами, которые реально есть в этом проекте. Карточка читается за секунды —
   **иллюстрация, которую агент нарисовал сам** под этот репозиторий, название и одна строка сути;
   звёзды автоматизируемости, находки разведки и «зачем это агенту» — под «подробнее».
   Отмечено не больше трёх срезов: выбор из трёх — решение, выбор из восьми — работа.
3. Пользователь отмечает нужное прямо на странице и жмёт «Отправить агенту» — **решение уезжает
   агенту само** (блокирующий `await` в стиле plannotator, работает и в Claude Code, и в Codex;
   копировать JSON в чат больше не нужно). Состав можно поменять и потом: вернулся на «Срезы»,
   щёлкнул карточку — агенту уедет «добавь этот срез» / «сними тот».
4. Агент извлекает выбранные срезы **параллельно** и выкладывает порции ревью по мере готовности.
   Слева всегда сайдбар: «Срезы → порции ревью → Эксплорер», у каждой порции видно состояние
   («извлекается» / «5 ждут вас» / «отправлено»), ревьюить можно в любом порядке — очереди
   «один срез за раз» нет. Уверенное (`high` + declared/observed + evidence) агент **подтверждает
   сам** с пометкой auto_approved; человеку едет только сомнительное: диаграмма, карточки фактов,
   ✓/✗/💬, секция «Нужен ваш ответ» сверху, авто-подтверждённое свёрнуто (можно отозвать).
5. После ревью — сохранение в **xmemory** (единственный источник истины: агент сам проектирует
   схему под выбранные срезы, схема эволюционирует; без xmemory — локальный fallback
   `~/.tech-facts/<проект>/` вне репозитория, о чём UI честно предупреждает жёлтой полосой).
6. Затем агент собирает из **конструктора блоков** сайт-эксплорер под конкретный проект
   (страницы и блоки выбирает по тому, что реально есть в системе): диаграммы, факты с evidence,
   таблицы, поиск, светлая/тёмная тема. Сайт — витрина над xmemory, перегенерируется в любой
   момент; всё рабочее живёт в `/tmp`, в репозиторий пользователя ничего не коммитится.
7. В будущей разработке любой агент перед задачей читает из xmemory релевантные факты (вместе с
   комментариями человека), после — актуализирует память и сайт. Каждое чтение/запись журналируются.

## Как это закрывает требования хакатона

- **Поток задач** — реальные задачи разработки в целевом репозитории (и реплей его истории в эвалах).
- **Цикл «выполнил → оценил → извлёк урок»** — задача выполнена → реальность кода сверена с
  памятью → расхождения становятся candidate-фактами / пометками stale.
- **Уроки меняют поведение** — следующий агент читает обновлённые active-факты перед задачей.
- **Память переживает рестарты** — внешнее хранилище (xmemory / файлы), каждый запуск агента —
  новый процесс.
- **Дельта чистая/обученная** — измеряется реплеем истории: [evals/README.md](evals/README.md).
- **Устаревание, противоречия, HITL, observability** — жизненный цикл факта
  (candidate → active → stale), авто-подтверждение с отзывом, журналы MemoryRead/MemoryWrite.

## Полевой тест

Скилл прогнан на реальном рабочем репозитории (services-platform, contract-first .NET): извлечено
37 фактов по 4 срезам, все прошли ревью; вторая итерация перенесла память в живой xmemory-инстанс
(цепочка «факт → ревью → задача» достаётся обходом графа, агентская выборка работает). 23 доработки
каталога и протокола по итогам внесены. Третья итерация — этот UI: один порт, авто-подтверждение,
конструктор сайта, обратная связь без копипасты.
