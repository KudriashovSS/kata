# Дизайн-система tech-facts UI

Одна дизайн-система на все стадии (picker → review → explore) и на любые блоки, которые агент
соберёт под проект. Шелл (`ui/`) уже реализует её; агент работает **данными, а не вёрсткой** —
но если добавляет custom-блок, обязан использовать эти токены, а не свои цвета.

Характер: спокойный операционный инструмент («control plane»), не лендинг и не маркетинг.
Плотно, но с воздухом; эмоций добавляют структура и статусы, а не градиенты. Light-first,
тёмная тема зеркалит каждый токен.

## Токены (канон — OKLCH, реализованы в `ui/styles.css`)

```
--canvas        light: oklch(1 0 0)            dark: oklch(0.17 0.005 260)
--surface       light: oklch(0.99 0.003 250)   dark: oklch(0.19 0.005 260)
--soft          light: oklch(0.97 0.005 250)   dark: oklch(0.22 0.005 260)   // сайдбар, чипы, hover
--border        light: oklch(0.93 0.005 250)   dark: oklch(0.28 0.008 260)
--text          light: oklch(0.22 0.005 250)   dark: oklch(0.88 0.005 250)
--text-muted    light: oklch(0.42 0.02 257)    dark: oklch(0.7 0.02 257)
--text-subtle   light: oklch(0.59 0.02 257)    dark: oklch(0.55 0.02 257)
--primary       light: oklch(0.5 0.2 255)      dark: oklch(0.68 0.17 250)    // действия, актив. навигация
--accent        light: oklch(0.56 0.17 168)    dark: oklch(0.74 0.16 168)    // связи, evidence, вторичная структура
--success       light: oklch(0.55 0.17 155)    dark: oklch(0.74 0.18 155)    // + soft-вариант для фонов бейджей
--warning       light: oklch(0.62 0.16 75)     dark: oklch(0.78 0.17 70)
--danger        light: oklch(0.55 0.24 25)     dark: oklch(0.68 0.2 25)
--info          light: oklch(0.58 0.2 240)     dark: oklch(0.72 0.16 240)
```

Семантика статусов факта (бейджи = soft-фон + сильный текст того же оттенка, никогда только цвет —
всегда подпись):

- `active` (подтверждён человеком) → success
- `auto` (авто-подтверждён агентом, можно отозвать) → accent
- `candidate` / «нужно ревью» → warning
- `stale` → нейтральный serый, зачёркнутый заголовок не использовать — только бейдж
- `rejected` → danger
- confidence: high/medium/low — точками ●●●/●●○/●○○ + текстом, low дополнительно warning-рамкой:
  сомнения должны бросаться в глаза.

## Типографика

- UI: `Inter` (Google Fonts) → системный fallback `-apple-system, Segoe UI, Roboto, sans-serif`.
- Код, id, evidence, пути: `JetBrains Mono` → `SF Mono, Menlo, Consolas, monospace`.
- Шкала: page-title 20/700, section 16/600, body 14/400 (line-height 1.55), meta 12/400,
  code 12.5/400. Никакой гигантской display-типографики — авторитет через структуру.
- Цифры в счётчиках — `font-variant-numeric: tabular-nums`.

## Слои, форма, плотность

- 4px-сетка. Карточка: padding 16, radius 8. Модалка/панель: radius 12. Кнопки/инпуты: radius 6.
  Бейджи — pill.
- Elevation функциональный: карточка = border + едва заметная тень; поповер = ступень выше;
  никаких glow/blur-спектаклей.
- Плотность dashboard: списки фактов компактные, но между секциями 24px воздуха.
- Sidebar — поверхность `--soft`, активный пункт — заливка `--primary` 10% + текст `--primary`.

## Движение

Движение — подтверждение действия, не украшение. 150–250ms, `ease-out`, transition только
именованных свойств (не `all`). Появление новых карточек — fade+4px подъём. Смена стадии
(picker→review) — мгновенная замена с короткой отбивкой заголовка. `prefers-reduced-motion` —
всё схлопывается. Нажатие: `:active { scale: 0.97 }` на кнопках.

## Обязательные мелочи (чеклист перед сдачей любого блока)

- Контраст текста ≥ 4.5:1 в обеих темах; статус никогда не передаётся только цветом.
- Иконки — inline-SVG (Lucide-стиль, stroke 1.5–1.75), не эмодзи.
- Все кликабельные элементы: `cursor: pointer`, видимый `:focus-visible` (2px ring `--primary`),
  hit-area ≥ 40px (расширять псевдоэлементом).
- Тёмная/светлая тема: переключатель system/light/dark в шапке, выбор в localStorage,
  `data-theme` на `<html>`; дефолт — system через `prefers-color-scheme`.
- Широкий контент (таблицы, диаграммы, код) скроллится в своём контейнере `overflow-x: auto`,
  страница горизонтально не скроллится.
- Звёзды автоматизируемости: ★★★★☆ рендерятся SVG-звёздами primary/`--border`, рядом текстовая
  подпись («извлекается автоматически / нужна валидация человека»).

## Диаграммы (mermaid, вендорен в `ui/vendor/`)

- Инициализация с `theme: "base"` и themeVariables из токенов — диаграмма обязана перекрашиваться
  при смене темы (перерендер по событию).
- Читаемость важнее полноты: ≤ 15 узлов на диаграмму, бизнес-имена узлов, глагол на каждом ребре
  (`produces`, `owns`, `calls`). Переполнение — резать по домену, а не уменьшать шрифт.
- Диаграмма в блоке: фон `--surface`, рамка `--border`, кнопки «копировать mermaid» и zoom
  (клик — открыть в оверлее покрупнее).
