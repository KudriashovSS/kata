# Стартовые факты для C0

Здесь лежат два артефакта:

- [`starting-slices.md`](starting-slices.md) — какие срезы собираем на C0 и почему именно они;
- `snapshot-c0.md` — **сам снапшот фактов, замороженный на C0**. Его кладёт сюда скилл
  `tech-facts`, отработав на коммите `551a92a03`. В репозитории файла нет намеренно.

Пока снапшота нет, `memory-on` не запускается вхолостую: SessionStart-хук вернёт ошибку,
раннер пометит прогон `memory_ok: false`, а `sweep` выкинет его из сводки. Это сделано
специально — прогон, в который память не приехала, это `memory-off` под другим именем,
и 36 таких прогонов дадут красивую таблицу со сравнением пустоты с пустотой.

Читаем из файла, а не из xmemory на каждой сессии: 36 прогонов этапа 1 — это десятки
живых чтений, а квоты у нас впритык. Для демо и для этапа 2 есть режим
`[memory].mode = "xmemcli"`, который ходит в память по-настоящему.
